# LeagueMates

Tee times, pairings and standings for a weekly golf league.

## Executive Summary

- Purpose: replace the weekly league spreadsheet with a web and mobile app for schedules, tee times, scorecards, handicaps, standings and photos.
- Status: **1.1.0** released 2026-10-18 (1.0.0 on 2026-10-17) and running in production at https://leaguemates.bhbslp.org (email limited to the owner's test addresses). What's in each release: [doc/Changelog.md](doc/Changelog.md).
